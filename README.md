# Агрегатор вакансий

Курсовая работа: «Разработка системы агрегации вакансий с применением методов нечёткой дедупликации и асинхронной обработки данных».

## О чём работа

Одна и та же вакансия публикуется сразу на нескольких площадках: сайтах поиска работы, в Telegram-каналах, на сайтах компаний. Система автоматически собирает вакансии из нескольких источников, отбирает подходящие по заданным критериям и убирает повторы.

## Основные задачи

**Нечёткая дедупликация.** Нужно определить, что две записи из разных источников описывают одну вакансию, хотя точного совпадения нет: «Junior Python Developer» и «Младший разработчик Python», разные написания компании, сокращённое или переформулированное описание. Сравниваются три подхода:

- редакционное расстояние (расстояние Левенштейна);
- коэффициент Жаккара и его быстрое приближение (MinHash);
- векторные представления текстов и косинусное сходство.

Критерии сравнения — точность (верно найденные дубликаты и ошибочные совпадения) и скорость на растущем объёме данных.

**Асинхронная обработка.** Источники опрашиваются параллельно, сбой одного не останавливает остальные. Эффект оценивается экспериментально: время последовательного и асинхронного сбора.

## Инструменты

Python, asyncio, PostgreSQL.
